# item/

自带物品的图标，**一件一个文件**（`.svg`，`viewBox 0 0 32 32` 最省事）。两个分区：

```text
item/item/<物品id>.svg   # 专属图标：有就用这张
item/tag/<tag>.svg       # 按标签兜底：物品没有专属图标时，按它的标签挑一张
```

**两色规则**：`#d7ddd2`（或 `currentColor`）是**底色**（→ 主题 `--ink`，近白），
其余颜色是**特征色**（→ 该物品的**品质色**）。所以同一张 tag 图用在蓝/紫/金物品上不会串色，
底色也不用自己操心。没有图标的物品会自动回退内置 `i-*` 零件。

同 id 由**包优先级**决定谁赢（把本包排到 `base` 之上即可替换内置图标）。
只改外观、**不进存档**。

详见 `resourcepacks/README.md`「物品图标 ——`item/`」与 `docs/ADD_CONTENT.md`。
