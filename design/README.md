# 冻结的界面设计稿（SVC / Linear Symbolic Minimalism）

本目录的 `svc-mock.html` 是**已冻结**的界面设计稿，作为本地 Web 应用的视觉与交互基准。

## 风格参数（沿用旧 Web 端 styles.css）
- 背景 `#0b0f10` / 面板 `#171e1e`→`#1d2625` / 线条 `#33403d`、`#27312f`
- 文字 `#e6eadf`，次级 `#9aa79f`；主强调 **琥珀 `#e2a84d`**
- 次强调 翡翠 `#68b998` / 砖红 `#d46b63` / 雾蓝 `#71a6c4`
- 品质六色 `#c4c9c4 / #66b875 / #6b9fd1 / #a77ad1 / #d6aa45 / #d86459`
- 字体：正文 `Microsoft YaHei UI` 等，标题楷体 `STKaiti`；数字/代号等宽
- 单线几何 SVG 图标（无 Emoji）；槽位 `--slot`（**实现现为 60px，早期稿写 54px**）

> ⚠️ 本稿是**冻结基准**，实现已演进（响应式、耐久条、发现界面、搜索两栏等）。
> **具体参数以 `docs/STYLE.md` §9「参数表」为准**；本文件只作设计意图与结构参考。

## 结构
- 顶栏：标题 / 局面摘要 / 难度（悬停显示全部 buff·debuff）/ 保存·读取·导出日志·新对局
- 左列：**可视日志**（竖排整列、常驻、自动滚动、不分页）
- 中列：避难所（门口 + 房客席位）；下方：屋主仓库 + 房客背包
- 右列：现有信息（上下约 2/3）+ 外出搜索（约 1/3），各自可滚动
- 羁绊：顶部细条（仅列已激活性格+位阶），点开左侧滑出「羁绊概况」抽屉

## 关键交互（已定）
- 物品：悬浮看详情（含风味）；单击使用/装备；**装备免选人**直接入包；可拖拽在仓库↔背包、仓库内、房客卡间移动/交换/使用
- 房客卡：固定 212×200；点开**原地展开详情**（技能含「使用」；被封印技能置灰+删除线+「已封印」）；点详情空白回席位
- 状态效果：卡下半显示一行 chip；悬停**具体状态**看详情、悬停**空白**看全部状态
- 羁绊：位阶按档数（2档银/金、3档铜/银/金、4档铜/银/金/棱彩）；**只高光当前档**；悬浮看效果（当前档高亮）+ 激活者/拥有者
- 仓库：固定展示区 + 内置滚动；容量 27 起步，将满时**自动 +9**
- 特殊状态形态：永续/无数值只显示名字；仅层数或仅强度显示一个数字
- 负生命=红条、负理智=紫条（负得越多条越长，数值同色）

> 设计稿为静态演示（假数据 + alert），真实数据与结算由 `weiren_game/web_ui.py` 接入。
