# 平衡改动记录

> 只记**对玩家可见的强度变化**。「为什么这么改、当时权衡了什么」→ `docs/DECISIONS.md`；
> 这里只记"改了什么"，方便日后回看一个技能被削/加强过几轮。
>
> - 新条目追加在**顶部**；同一角色同一天写在同一节里。
> - 标记只有五个：`【新增】` `【移除】` `【重做】` `【增强】` `【削弱】`。
> - 一行一条变化，用 `前 → 后`；纯新增写 `— → 内容`。
> - 数值**必须写具体数字**（`10 → 4`），不写"略微调整"——不然这条记录没有用。
> - 技能名用游戏内显示名（不写模块里的 id）。

## 【待实施】葱头 / 沙白 / ED Tear · 2026-09-18

> 下一批平衡改动的**定稿文本**：先记账，改完代码后把本节标题里的「【待实施】」去掉。
> **整条重做**的技能只写"前 → 后"（不再逐项罗列）；行文中没写死、需要设计拍板的，留在对话里，不写进账本。

### 葱头「情绪显现-共情」— 增强

改动前：只显示**烦躁**的强度与层数；葱头自身免疫烦躁。
改动后：显示所有房客的**【侵蚀情绪】**的强度与层数；葱头自身免疫烦躁不变。

修改内容：

- 【重做】技能名：情绪显现-烦躁 → 情绪显现-共情
- 【增强】可见范围：烦躁 → 全部侵蚀情绪

### 葱头「平静」— 重做（范围增、加上限）

改动前：房客获得**烦躁**时 30% 免疫；触发则葱头获得 1 个共情印记（至多 3 个）。
改动后：房客获得**任意侵蚀情绪**时 30% 免疫（**烦躁提升为 45%**）；触发则葱头获得 1 个印记（至多 3 个）；
**每名房客每回合最多触发一次**。

修改内容：

- 【增强】免疫范围：烦躁 → 全部侵蚀情绪
- 【增强】烦躁免疫率：30% → 45%
- 【削弱】触发上限：无 → 每名房客每回合 1 次

### 葱头「情绪剥离」— 增强（范围 + 兜底）

改动前：移除目标**烦躁**；消耗 1 个共情印记或 15 理智；消耗印记时双方额外回复 5 理智；冷却 2 回合。
改动后：选择一名房客与其**一种侵蚀情绪**移除；其余同上；**目标没有任何侵蚀情绪时**改为：
使其消沉值 **−10%** 并回复 **3** 理智。

修改内容：

- 【增强】可移除对象：烦躁 → 任意侵蚀情绪（玩家指定）
- 【新增】空目标兜底：— → 消沉 −10% + 回复 3 理智

### 葱头「群体心理疏导」— 重做（代价与效果同升）

改动前：消耗 **3** 个共情印记；移除所有房客的**所有情绪负面**；消沉 **−75%**；每局 1 次。
改动后：消耗 **3** 个共情印记；移除所有房客的所有**【侵蚀情绪】**；消沉 **−75%**；
**每移除一种情绪该房客回复 1 理智；没有任何情绪者回复 3 理智**；每局 1 次。

修改内容：

- 【削弱】可移除范围：所有情绪负面（侵蚀 + 觉醒）→ 仅侵蚀情绪
- 【增强】新增按条回复：— → 每移除一条 1 理智 / 无情绪 3 理智

> 说明：**代价 3 印记与消沉 −75% 当前文案已经是**，所以这条的实际 delta 只有"范围收窄 + 按条回复"。

### 沙白 被动①「家里蹲」— 重做（整条替换，不逐项罗列）

改动前：万事通——搜索返回时 30% 额外获得一件物资；回合开始时 20% 使创伤强度 ≤3 的房客创伤 −3（冷却 3 回合）。
改动后：被接纳时获得 5 层鼓舞；每个回合结束时为所有房客回复 2 理智；
每次摄入紫色及以上品质的食物获得 3 层鼓舞（最多 5 层）。

> 「鼓舞」是**特殊 condition**：固定 1 强度、**不显示**，也不是情绪。

### 沙白 被动②「勤俭节约」— 重做（整条替换，不逐项罗列）

改动前：感知迟钝／困倦——理智消耗 / 增加量 ×50%；入住时理智 50；搜索返回后 3 回合不能搜索。
改动后：每个回合开始时，若沙白理智 >80，本回合**第一个【耐久度消耗品】不消耗耐久**；
理智 >90 时**再多免一个**（一回合最多 2 次，**跨回合不累计**）。

### 沙白 主动「紧急脱出装置」— 新增

改动前：沙白没有主动能力。
改动后：若本回合有伪人来访，可令**本次来访固定推迟 2 回合**；代价为 **25 理智**或一件**金色及以上**品质物品。

修改内容：

- 【新增】紧急脱出装置（— → 本次伪人来访推迟 2 回合）

### ED Tear 物品「沃尔玛购物袋」— 削弱

改动前：搜索返回后有 25% 可能被消耗；携带者为 ED Tear 时消耗概率 −10%。
改动后：ED Tear 使用消耗率 **15%**；其他房客使用后**必定消耗**。

### ED Tear「我不能没有购物袋」— 重做（整条替换，不逐项罗列）

改动前：ED Tear 自身不携带购物袋时，回合末理智消耗 ×3 且额外 +5。
改动后：**全游戏**（所有房客含在外搜索者 + 屋主仓库）都没有购物袋时，回合末消耗 **25 理智**，
并为自己装备一件购物袋。

改动前：任何**回复生命**（只要回到 >0）都会顺手**清除休克**。

- 【增强】休克的持续威胁：回合末的死亡 / 加深判定不再被一次回血抹掉

## 混 · 2026-09-18

### 「情绪显现-理智／癫狂」— 重做（改名，无数值变化）

改动前：这条情绪叫「理智」，字面与**理智值**（0~100 的数值）撞名。玩家会以为"混有理智就能解锁纯真的自我"，
而实际判据是**情绪的层数**（`tenant.reason.layers >= 10`），与理智值无关。
改动后：情绪改名为「**清醒**」；相关文案、CLI 说明、太极图进度提示同步改口径。
内部 id 仍是 `reason`，**老存档不受影响**。

修改内容：

- 【重做】情绪显示名：理智 → 清醒
- 【重做】技能显示名：情绪显现-理智／癫狂 → 情绪显现-清醒／癫狂
- 【增强】可读性：详情页太极图未解锁时显示「清醒情绪 N/10 层」进度（— → 进度提示）

## 花尔维纳 · 2026-09-17

### 「园艺达人」— 新增

改动前：花尔维纳没有专属技能（原稿备注："原稿无专属技能，仅参与通用系统"）。
改动后：详情页可以打开一块**田**——两块地，种【食物】、浇【矿泉水】，成熟后收成。

修改内容：

- 【新增】田：2 块地；一块地一次只种 1 件【食物】，种下之后取不出来。
- 【新增】湿润度 0 ~ 3：浇水回满，每回合 −1；> 0 才会生长。
- 【新增】生长：每回合 +1 进度；本回合与上回合都是满水 → +2；进度到 7 成熟。
- 【新增】干旱代价：水分 = 0 连续 2 回合 → 最大产物量 −1；连续 3 回合 → 枯死；
  产物量被扣到 0 等同枯死。
- 【新增】收成：成熟后自动落到"产物格"，一次 3 份（会被干旱扣减），拖进仓库即收下。
