# 平衡改动记录

> 只记**对玩家可见的强度变化**。「为什么这么改、当时权衡了什么」→ `docs/DECISIONS.md`；
> 这里只记"改了什么"，方便日后回看一个技能被削/加强过几轮。
>
> - 新条目追加在**顶部**；同一角色同一天写在同一节里。
> - 标记只有五个：`【新增】` `【移除】` `【重做】` `【增强】` `【削弱】`。
> - 一行一条变化，用 `前 → 后`；纯新增写 `— → 内容`。
> - 数值**必须写具体数字**（`10 → 4`），不写"略微调整"——不然这条记录没有用。
> - 技能名用游戏内显示名（不写模块里的 id）。

## 混 · 2026-09-18

### 「情绪显现-理智／癫狂」— 重做（改名，无数值变化）

改动前：这条情绪叫「理智」，字面与**理智值**（0~100 的数值）撞名。玩家会以为"混有理智就能解锁纯真的自我"，
而实际判据是**情绪的层数**（`tenant.reason.layers >= 10`），与理智值无关。
改动后：情绪改名为「**清醒**」；相关文案、CLI 说明、太极图进度提示同步改口径。
内部 id 仍是 `reason`，**老存档不受影响**。

修改内容：

- 【重做】情绪显示名：理智 → 清醒
- 【重做】技能显示名：情绪显现-理智／癫狂 → 情绪显现-清醒／癫狂
- 【增强】可读性：详情页太极图未解锁时显示「清醒情绪 N/10 层」进度（— → 进度提示）

## 花尔维纳 · 2026-09-17

### 「园艺达人」— 新增

改动前：花尔维纳没有专属技能（原稿备注："原稿无专属技能，仅参与通用系统"）。
改动后：详情页可以打开一块**田**——两块地，种【食物】、浇【矿泉水】，成熟后收成。

修改内容：

- 【新增】田：2 块地；一块地一次只种 1 件【食物】，种下之后取不出来。
- 【新增】湿润度 0 ~ 3：浇水回满，每回合 −1；> 0 才会生长。
- 【新增】生长：每回合 +1 进度；本回合与上回合都是满水 → +2；进度到 7 成熟。
- 【新增】干旱代价：水分 = 0 连续 2 回合 → 最大产物量 −1；连续 3 回合 → 枯死；
  产物量被扣到 0 等同枯死。
- 【新增】收成：成熟后自动落到"产物格"，一次 3 份（会被干旱扣减），拖进仓库即收下。

## 柳七鱼 · 2026-09-17

### 「不行，我要受不了了」— 削弱

改动前：驱逐时获得 10 份随机物资；并按目标已损失生命给时运加成（基础 +5，每损失 10 点 −1，最低 −5）。

修改内容：

- 【削弱】获得物资：10 → 4
- 【移除】按已损失生命的时运加成：基础 +5 / 每 10 点 −1 / 最低 −5 → 无
- 【新增】使用后自身额外伤害：— → 2
