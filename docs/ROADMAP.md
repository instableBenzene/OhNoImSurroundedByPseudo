# 路线图（想做的系统 · 讨论结论）

> 这份记的是**还没做、但方向已经聊清**的东西。已做的决策在 `docs/DECISIONS.md`，
> 平衡账在 `docs/BALANCE.md`。每条都写明：**现成能复用什么**、**要新造什么**、**动手前必须回答什么**。

## 1. 游戏模式：无尽模式 / 故事模式

**好消息**：两者都不该改核心，而是"一组规则 + 一张表"——符合 `docs/PRINCIPLES.md` §二.5。

- **无尽模式**：游戏永不结束；伪人**不定期重刷**；死亡房客与已解放的伪人**若干回合后回到池子**；看撑多久。
  - 复用：`_finish()` 是唯一的结束口 → 无尽下不调用即可；`_roll_next_pseudo_visit` + `visitor_pool`
    已经是"重刷/回池"的现成通道（拒绝与离开都走过它）；`pseudo.liberated/known/revealed` 重置即为重刷。
  - 要新造：**模式定义**（结束条件 / 重刷间隔 / 回池规则），建议放内容层（`data/`）当"模式表"，
    开局页与「地图」「伪人」并列出一个下拉。
  - 要回答：重刷时**换不换伪人**（同场景重置 vs 换 `scenario_id`）；图鉴/羁绊的账怎么算（死亡回池要不要保留羁绊进度）。
- **故事模式**：本质是**特殊种子**——开局有谁、第几回合发生什么都是固定的；配套**剧情文本**与**角色对话**。
  - 复用：确定性 RNG + `start_choices` + `next_pseudo_turn` 已能复现"何时发生什么"；
    剧情文本走**信息/事件**通道（`kind`/`subtype`/`data` 都在）；展示走既有提醒。
  - 要新造：**按回合排定的剧本表**（如 `STORY_SCRIPT = ((1, …), (3, …))`），由系统在回合开始查表触发。
  - 要回答：剧本表与**全局事件**的关系（建议同构：剧本 = 预置的全局事件，别再造第三套提醒）。

## 2. 对话系统（galgame 式对话框）

**空间问题其实是"层级"问题**，不是"没地方放"：

- **入口**收敛到"**选中房客之后**"——展开卡的标题行，与「指认」同一处（`docs/STYLE.md` §10.3/§10.7 的既有范式）。
  反面教材就是「驱逐」：塞在每张头像脸上，正是因为没有先选中谁。
- **对话框**用**贴底悬浮**（背包 / 外出搜索那种），不用阻塞式弹窗：底部一条，左侧头像走 `avatarIcon()`，
  正文走 `mdText()`（对话换行规则已经就位）。
- **闲聊**不要"从头顶冒气泡"（突兀）——建议**进日志/信息条**：闲聊 = 一条带说话人的可点开日志（多句折在明细里，
  正好复用刚统一的 log 层折叠）；或者作为「现有信息」的一类。
- **契约**：对话内容是内容层声明的（`LINES`/`DIALOGUE`），系统只负责"什么时候问一句、怎么显示"——
  与 `PENDING_VIEWS` 同构，别在系统里写死任何台词。

## 3. 战斗：伪人不设血条，只由**规则**制衡

**这是设计底线，不是待办**：伪人不该有血条，驱逐/解放要像规则怪谈那样用**规则**完成，而不是把数值打到 0——
否则角色强度会退化成"数值比较"，将来必然膨胀。

- 现成骨架就在：**闸门**（`gate`/`NODE_HOOKS`）是纯查询的布尔条件；洋葱的解放（连续无烦躁 / 无生命损失）、
  苯的「早交班」、薯条的「暴露值 ≥25」都是"规则制衡"的实例。将来所谓"战斗"应该是**声明式规则对撞**
  （多个 gate 叠加 + 内容自述反制条件），不是 HP 交换。
- **建议写成硬性约束**（`docs/PRINCIPLES.md` 或本文件当权威）：**伤害可以当规则的输入，但不能当"打到 0"的判据**；
  伪人卡不显示血条；一切"击败"必须能复述成一条可阅读的规则。

## 4. 存档结构迁移（与上面三条独立，但迟早撞上）

- 现状：`meta.version` 会写盘、`from_dict` 对未知字段严格报错，但**没有迁移**；
  字段后加（如 `log.entries`）甚至**没升版本号**，于是同一版本号下住着两种结构。
- 要回答：① 什么时候必须升版本（字段增删 vs 语义变化）；② 迁移写在哪层（`from_dict` 逐级升 /
  开局统一跑一遍）；③ 失败时拒读还是"尽力读 + 明确告知缺了什么"。
- 相关踩坑见 `docs/DECISIONS.md`「导出的游戏记录不从第 1 回合开始」。
