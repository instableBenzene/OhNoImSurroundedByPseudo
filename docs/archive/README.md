# 归档（archive）

> **非现行参考：不要主动读，除非你在追溯某次改动、或者要把它回滚回来。**

这里放"已经不成立"的东西：旧任务书、被替换掉的实现与数值、为了回滚而留下的旧版本快照。

- **不参与任何扫描**：一律用 `.md` + 围栏代码块（不是 `.py`），所以 `compileall`、单测、
  `validate_content`、`audit_separation` 都不会碰到它，也不会被误 import。
- **不是第一手资料**：任何结论都以现行代码与 `docs/*.md` 为准；归档只负责"当时那段东西的原样"，
  不解释自己、不保证还成立。
- **索引在两处**：数值变化看 `docs/BALANCE.md`，决策与原因看 `docs/DECISIONS.md`。

命名：`code/<角色或系统>_<YYYYMMDD>.md`。
